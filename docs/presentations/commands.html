Cómo usar este catálogo

Todos los comandos se ejecutan desde la raíz del repo con npm run <script>. No requieren intervención de la IA: son herramientas directas para operar, verificar y mantener el stack. Usa el buscador para filtrar por nombre, descripción o referencia.

Sin resultados para el filtro actual.
🎛️

Command Center

Panel standalone en http://127.0.0.1:8090 para iniciar, detener y consultar las apps construidas de forma idempotente.

npm run cc:start

Inicia la UI del Command Center.

npm run cc:server

Sirve la API/UI sin abrir el navegador.

npx tsx src/cli/gv.ts cc start|stop|status

Controla el ciclo de vida desde la CLI.

Las apps se ejecutan on-demand y permanecen activas entre sesiones si están sanas.
