Fundamentos de Ingeniería de Software

🔄
Spec-Driven Development (SDD)

Ciclo explorar → diseñar → implementar → verificar con documentos por fase (BAD, SAD, PAD, ADV) y contratos de validación.

Aplicación en GV Agentes sdd-explore → sdd-design → sdd-apply → sdd-verify con contract_results en Nexus (contract_results).
Ejercicio

Traza un feature desde BA hasta QA identificando el documento de cada fase.

📥
Receipt-Driven Development (RDD)

Desarrollo guiado por recibos de revisión: cada cambio genera evidencia que se registra y se usa como retroalimentación.

Aplicación en GV Módulo RDD completo en src/rdd/ con kill-switch y gestión de recibos por cambio.
Ejercicio

Revisa un commit tuyo y escribe el recibo de revisión con 3 aprendizajes.

🐙
Git Workflow y Ramas

Estructura de ramas, commits por unidad de trabajo, PRs encadenados y gestión de versiones.

Aplicación en GV Skills git-workflow-and-versioning, work-unit-commits, chained-pr y branch-pr.
Ejercicio

Divide un cambio de 400+ líneas en PRs encadenados revisables.

🧠
ADRs y Decisión Arquitectónica

Documentar decisiones de arquitectura con contexto, consecuencias y alternativas.

Aplicación en GV docs/adr/ con ADR-0001 a ADR-0012 (knowledge absorption, M6 tiering, etc.).
Ejercicio

Escribe un ADR de una decisión técnica reciente usando la plantilla del skill.

🛠️
Karpathy Guidelines

Estándares de código: Think First, Simplicity, Surgical Changes, Goal-Driven.

Aplicación en GV Normativas en rules/ y el pipeline los aplica como guías de cada sesión.
Ejercicio

Revisa un refactor y evalúalo contra las 4 guías de Karpathy.

🔍
Doubt-Driven Development

Revisión adversarial con contexto fresco para código crítico, desconocido o de alto riesgo.

Aplicación en GV Skill doubt-driven-development: sesiones de revisión de "contexto fresco".
Ejercicio

Toma un archivo que no escribiste tú y busca 3 suposiciones falsas.

🤖

Fundamentos de IA / LLM

📚
RAG (Retrieval-Augmented Generation)

Generación asistida por recuperación: contexto relevante + modelo para responder con base factual.

Aplicación en GV src/rag-retrieval.ts recupera contexto de skills/normas/docs para las respuestas.
Ejercicio

¿Qué chunk recuperarías para "¿qué es Nexus?" y por qué?

🎯
CRAG (Corrective RAG)

Gradúa la relevancia del retrieval y corrige con keyword-fallback si es pobre, evitando alucinaciones.

Aplicación en GV src/retrieval-grader.ts gradea chunks con BM25 y dispara fallback.
Ejercicio

Ejecuta npx tsx src/retrieval-grader.ts con chunks irrelevantes y observa el veredicto.

🧮
BM25 y TF-IDF

Relevancia lexical: frecuencia de términos ponderada por rareza. Sin ML, rápido y explicable.

Aplicación en GV retrieval-grader y web-research-select usan BM25 para scoring de resultados.
Ejercicio

¿Por qué "el" tiene peso ~0 en BM25? Explica con TF-IDF.

🧊
Embeddings y Búsqueda Vectorial

Representar texto como vectores y buscar por similitud coseno (ANN/HNSW).

Aplicación en GV src/ml-embeddings/ indexa skills, normas y docs para búsqueda semántica.
Ejercicio

¿Qué embedding usarías para "checkpoint"? Propón su vecino semántico.

🪙
Tokens y Presupuestos

Unidad mínima de procesamiento del LLM. Presupuestos diarios/por sesión evitan sobreconsumo.

Aplicación en GV token-ingest lee tokens reales (agnóstico) y token-budget-guard fija 5M/día y 3M/sesión.
Ejercicio

Ejecuta npm run token:status y explica qué cifra domina el consumo.

🛡️
Seguridad de LLMs (OWASP LLM Top 10)

Injection, leakage de prompts, tool poisoning, excesos de agencia y más riesgos específicos de aplicaciones LLM.

Aplicación en GV 25 skills de ciberseguridad (red-teaming, guardrails, RAG injection, MCP auditing).
Ejercicio

Identifica 3 vectores de injection indirecta en un chatbot de docs.

📈
RLHF, DPO, SFT

Alineación de modelos: Supervised Fine-Tuning, Reinforcement Learning from Human Feedback y Direct Preference Optimization.

Aplicación en GV research/rlhf-dataset-search/ busca datasets de preferencias y reward models.
Ejercicio

Busca un dataset RLHF con el script de research y clasifica su fuente.

⚙️

Infraestructura y Operaciones

🔗
Tracing Distribuido (OTLP)

Seguimiento de peticiones a través del sistema con spans en árbol trace_id → span_id.

Aplicación en GV src/tracing-instrument.ts con spans en .telemetry/ y export OTLP al puerto 4318.
Ejercicio

Traza una operación del stack y dibuja su árbol de spans.

💾
Checkpoints, Snapshots y Rollback

Puntos de restauración del estado para recuperación ante fallos.

Aplicación en GV checkpoint-manager, snapshot-manager y rollback-orchestrator con dry-run.
Ejercicio

Crea un checkpoint, haz un cambio y restaura con rollback dry-run.

🧾
Event Sourcing y Saga

Store append-only de eventos con consistencia y compensación de transacciones distribuidas.

Aplicación en GV event-sourcing.ts con hash-chain SHA-256 (tamper-proof) y saga-orchestrator.
Ejercicio

Append 3 eventos y ejecuta verify; rompe uno y observa tamper-mismatch.

⏱️
Circuit Breaker

Previene cascadas de fallos: CLOSED → OPEN (5 fallos) → HALF_OPEN → CLOSED (2 éxitos).

Aplicación en GV src/circuit-breaker-api.ts aplicado a los cloud connectors híbridos.
Ejercicio

Simula 6 fallos y describe la transición de estados del breaker.

🩺
Health Checks y Watchtower

Monitoreo continuo con auto-healing de procesos caídos.

Aplicación en GV maintenance-watchtower: 95 checks en 13 componentes, 6 modos de acción.
Ejercicio

Ejecuta npm run watchtower:health y clasifica los 13 componentes.

📊
SLOs y Error Budget

Objetivos de nivel de servicio con presupuesto de error y métricas de latencia (P95/P99).

Aplicación en GV src/performance-slo-monitor.ts con alertas del dashboard.
Ejercicio

Define un SLO de 99% y calcula el error budget mensual.

Bases de Datos y Persistencia

🔩
SQLite y WAL

Aplicación en GV Nexus (.runtime/gentle-vanguard.db) en WAL mode con FK ON y auto checkpoint.
Ejercicio

Consulta las tablas de Nexus y explica qué almacena cada una.

📜
Migraciones de Esquema

Evolución versionada del esquema aplicada de forma idempotente.

Aplicación en GV Migrations 001-003 en apps/web-dashboard/server/database/ (12+ tablas).
Ejercicio

Identifica a qué migración pertenece session_scoring y por qué.

🔎
FTS5 (Full-Text Search)

Búsqueda full-text de SQLite con indexación de texto y consultas MATCH.

Aplicación en GV Engram y CodeGraph usan FTS5 para búsqueda de observaciones y símbolos.
Ejercicio

Busca "checkpoint" con FTS5 en Engram y compara con LIKE.

⛓️
ACID y Transacciones

Garantías de atomicidad, consistencia, aislamiento y durabilidad.

Aplicación en GV Las operaciones de Nexus (init, prune, backup) son transaccionales.
Ejercicio

¿Qué pasaría si una migración falla a medias sin transacción?

🧊
Caché y TTL

Respuestas cacheadas con clave SHA-256, TTL y conteo de hits.

Aplicación en GV Tabla response_cache de Nexus con pruning >7 días.
Ejercicio

¿Cómo se invalida una respuesta de caché cuando cambia el prompt?

🗃️
Backup y Prune

Copias online seguras y depuración de datos viejos para mantener salud.

Aplicación en GV npm run db:backup/restore/prune con retención de 10 backups.
Ejercicio

Realiza un backup y comprueba su integridad con db:health.

Comunicación y Protocolos

🔌
MCP (Model Context Protocol)

Protocolo estandarizado para exponer herramientas y contexto a modelos.

Aplicación en GV Servidor MCP del stack (config/mcp.json) expone utilidades a los agentes.
Ejercicio

Audita un servidor MCP con el skill de tool-poisoning.

🔁
WebSocket

Comunicación bidireccional full-duplex en tiempo real sobre TCP.

Aplicación en GV websocket-server.ts del dashboard envía métricas cada 5s (puerto 8080).
Ejercicio

Conecta con wscat al WS y observa el broadcast de métricas.

🛰️
REST APIs

APIs sobre HTTP con verbos, recursos y estados bien definidos.

Aplicación en GV El WS server expone /api/metrics, /api/traces, /api/alerts, /api/health.
Ejercicio

Invoca /api/health y lista los 7 componentes que responde.

🌐
Proxy y Puertos Dinámicos

Asignación de puertos libres y proxying en desarrollo para evitar colisiones.

Aplicación en GV Get-FreePort() en dashboard-common.ts y proxy de Vite hacia WS_PORT.
Ejercicio

Revisa .runtime/dashboard-ports.json y explica por qué cambia de puerto.

🔐
Seguridad en Tránsito

TLS/HTTPS, autenticación en handshake y prevención de hijacking (CSWSH).

Aplicación en GV Skill testing-websocket-api-security audita handshakes y mensajes.
Ejercicio

¿Qué validarías en el upgrade handshake de un WebSocket?

🚪
gRPC y GraphQL (referencia)

Protocolos alternativos: RPC binario tipado y query language para APIs.

Aplicación en GV Documentados en el skill api-and-interface-design; no usados en el core.
Ejercicio

Compara REST vs GraphQL para el caso del dashboard.
