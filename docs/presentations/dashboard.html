1. Dashboard Overview i

Stack

React / TypeScript / Vite SPA — real-time WebSocket data pipeline with HTTP polling fallback. All metrics derive from live .state.json traces; no mock data exists in the system.

i18n

Full internationalization across 3 languages — English, Español, Português (BR). 14 metric descriptions translated and managed through the useLocale hook.
