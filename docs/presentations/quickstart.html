🔧 Troubleshooting

Common issues and their solutions

Autostart fails steps

Check logs in logs/session-autostart.log for the specific step that failed. Most failures are transient — re-run the command.

Dashboard won't start

Check .runtime/dashboard-ports.json for port conflicts. Kill the process on the conflicting port and retry.

Tests fail

Run npm run typecheck and npm run lint first. Fix any type/lint errors, then re-run npm test.

Database issues

Run npm run db:optimize to WAL checkpoint, REINDEX, and VACUUM. If corruption is suspected, restore from backup via npm run db:restore.
