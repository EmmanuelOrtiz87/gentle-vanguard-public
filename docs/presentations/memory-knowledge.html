🌐 Graphify — Knowledge Graph

i

LLM-extracted relationships with community structure and god nodes

Graph Details

  • Graph file: graphify-out/graph.json (18MB)

  • God nodes for high-level architecture navigation

CLI Commands

Natural language search across the graph

Focused explanation by exact node ID
