# Gentle-Vanguard 3D Logo Proposals

Tres direcciones premium inspiradas en la referencia compartida: simbolo central, material, luz
lateral, profundidad y una composicion editorial limpia. Todas respetan el canon v2 Premium y
mantienen el monograma G+V como base.

- **Obsidian Prism:** metal anodizado negro, profundidad y borde cyan-violet.
- **Aether Signal:** vidrio optico, refraccion y una lectura mas luminosa.
- **Precision Alloy:** titanio cepillado, construccion medida y tono institucional.

Son propuestas de laboratorio. El logo oficial operativo continua siendo assets/logo.svg hasta que
se elija una direccion.
