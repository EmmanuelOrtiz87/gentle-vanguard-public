# Gentle-Vanguard Logo Proposals / 2026-09

Exploracion no oficial de evolucion del monograma **G+V**. Ninguna propuesta reemplaza a
`assets/logo.svg` hasta una decision explicita.

## Direcciones

### A / Vector Gate

Evolucion directa del monograma actual. El arco G y el V comparten una arquitectura de trazos y
generan una lectura de puerta hacia adelante. Es la opcion de menor riesgo y mejor continuidad.

### B / Command Frame

El G+V vive dentro de un marco modular. Comunica sistema, control, observabilidad y arquitectura. Es
la opcion mas institucional para software, consultoria y equipos tecnicos.

### C / Orbital Signal

El monograma se combina con una orbita de senal. Comunica IA, aprendizaje y movimiento, con mayor
energia para Academy, workshops y redes sociales. Es la opcion mas expresiva.

## Criterios de evaluacion

- Reconocimiento del G+V en 16, 32 y 64 px.
- Legibilidad monocromatica y sobre fondos claros/oscuros.
- Capacidad de funcionar como avatar, favicon, wordmark, badge y patron.
- Coherencia con v2 Premium y el tono de empresa de ingenieria.
- Distancia suficiente de simbolos genericos de IA.

**Recomendacion preliminar:** A si se prioriza continuidad; B si se prioriza autoridad
institucional.
