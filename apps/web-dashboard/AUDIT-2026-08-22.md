## Top 5 wins ya en producción

1. **Pipeline real-time unificado**: WS 5s metrics + 200ms file-watcher debounce + 3s event-bus poll en una sola app React/Vite/Tailwind con 9 lazy routes (`App.tsx:20-29`).
2. **AG-UI + HITL + Shared-State CopilotKit patterns**: 7 `ui_hints` renderers, 4-mode HITL modal, event-bus delta channels — diferenciador único vs Datadog/Grafana.
3. **SQLite unificado**: 12 repositorios, WAL, migrations tracked, housekeeping cada 20 snapshots — base sólida para F1 (time-series).
4. **i18n con metric-dictionary**: en/es/pt-BR con copy "what/how" por métrica — base para A7 (full i18n).
5. **Stack Capability Matrix**: anomalías + circuit breakers + DB self-healing en una sola pantalla — el "self-healing infrastructure" ya se ve.

## Top 5 gaps (resueltos en el plan maestro)

1. **No time-range selector** — cada panel es "live last 5s" o "all-time" — gap #1 vs Datadog/Grafana/PostHog.
2. **Tests mínimos** — 20% coverage aprox; CI no puede refactorizar.
3. **Placeholders en producción** — `byModel` sintético, "Install Skill" no-op, `_useWebSocketMode` ignorado, README desincronizado (3 versiones distintas reportadas).
4. **Sin auth/RBAC/notif externas** — no enterprise-ready pese a tener la data shape.
5. **Bundle y deps obsoletas** — Recharts (150KB) usado en 1 componente, lucide 0.294 (2+ años), eslint 8.57 EOL.
